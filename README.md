# She Can Foundation

## Project Overview

She Can Foundation is a full-stack women empowerment web application developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

The project is designed to support women empowerment through technology by providing a modern platform with authentication, contact management, image upload, and an admin dashboard.

---

## Features

* User Registration System
* User Login Authentication
* Secure Admin Dashboard
* Contact Form Submission
* Image Upload Functionality
* MongoDB Database Integration
* Contact Management
* Search Feature
* Delete Feature
* Responsive User Interface
* Dark Mode Support
* Pagination Feature

## Installation Steps

### Step 1

Clone the repository

```bash
git clone https://github.com/vaishnavithattepally03/she-can-foundation.git
```

### Step 2

Install dependencies

```bash
npm install
```

### Step 3

Start MongoDB

```bash
mongod
```

### Step 4

Run the server

```bash
node server.js
```

### Step 5

Open browser

```text
http://localhost:3000
```
