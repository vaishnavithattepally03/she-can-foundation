# She Can Foundation

## Project Overview

She Can Foundation is a full-stack women empowerment web application developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

The project provides:

* User Registration
* User Login Authentication
* Contact Form Submission
* Image Upload Feature
* Admin Dashboard
* Message Management
* Responsive User Interface

This project aims to empower women through technology and digital innovation.

## Installation

### Step 1

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/she-can-foundation.git
```

### Step 2

Install dependencies

```bash
npm install
```

### Step 3

Start MongoDB

```bash
mongod
```

### Step 4

Run the project

```bash
node server.js
```

### Step 5

Open browser

```text
http://localhost:3000
```
